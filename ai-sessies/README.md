# AI-sessies

Bij elke PR die met AI is gemaakt, staat hier het **ruwe transcript** van de sessie: wat er gevraagd is, wat de AI las, deed en antwoordde, en welke toestemming de mens gaf. Zo is elke wijziging herleidbaar.

- Structuur: `ai-sessies/<branch>/<sessie-id>.jsonl`, met de subagents in `subagents/`.
- Onbewerkt, vastgelegd met `npm run transcript` vlak voor de PR. Vóór het vastleggen gescand op geheimen.
- De laatste beurten (het vastleggen zelf en het maken van de PR) staan er niet in.
